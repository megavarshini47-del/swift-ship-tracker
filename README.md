Swift Ship Tracker

  Swift Ship Tracker is a simple application for tracking ships and viewing their current location and status.The project is designed to make ship tracking easier by displaying useful information in one place. It can be used to monitor ships, check their location, and keep track of their movement.

Features:
  1.Track ships and their locations
  2.View ship details and status
  3.Simple and easy-to-use interface
  4.Search for ships
  5.Display ship movement and tracking information
  
Technologies Used:
  a)Swift
  b)SwiftUI
  c)Xcode
  d)MapKit
  
Getting Started:
To run this project on your computer,
   1.Clone the repository.
   2.Open the project in Xcode.
   3.Make sure the required dependencies are installed.
   4.Build and run the project on a simulator or a real iOS device.
   
Project Structure:
The project is organized into different parts to keep the code clean and easy to understand.
    a)Views - Contains the user interface
    b)Models - Contains the data models
    c)Services - Handles API and data-related operations
    d)Resources - Contains project resources and assets
    
How It Works:
  The application gets ship tracking information and displays it to the user. Users can select or search for a ship to view more information about its location and current status.

Future Improvements:
